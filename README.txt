سامانه مسجد - پروژه اندروید

پیش‌نیاز: Android Studio و Android SDK 35

روش باز کردن:
1) فایل ZIP را استخراج کنید.
2) Android Studio را اجرا کنید و Open را بزنید.
3) پوشه SamanehMasjed را انتخاب کنید.
4) پس از پایان Gradle Sync، از منوی Build گزینه Build APK(s) را انتخاب کنید.
5) فایل خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

این نسخه یک پوسته اندرویدی WebView است. محتوای داخلی دو پنل از وب‌سایت بارگذاری می‌شود و در این پروژه بازطراحی نشده است.
برای بارگذاری پنل‌ها اینترنت لازم است. این نسخه هنوز روی دستگاه واقعی آزمایش نشده است.
